# B 站关注管理器

一个 Tampermonkey 油猴脚本，在 **自己的 Bilibili 关注页** 增加独立管理面板，方便筛选关注账号并执行批量操作。

## 安装

1. 在浏览器中安装 [Tampermonkey](https://www.tampermonkey.net/) 并启用。
2. 在 Tampermonkey 中新建脚本，用 [`bili-follow-manager.user.js`](./bili-follow-manager.user.js) 的全部内容替换编辑器内容并保存。也可以在支持本地脚本安装的浏览器中直接打开这个 `.user.js` 文件。
3. 登录 Bilibili，进入**自己的**“关注”页面，点击右下角的“管理关注”。

## 使用

- 面板会逐页读取关注账号和分组。点击“全部”可显示完整列表；点击“未分组”可只看没有加入自建分组的账号；点击一个分组只看该组，同时点击多个分组则显示属于其中任一分组的账号。“特别关注”有独立筛选项，只有特别关注而没有自建分组的账号也会出现在“未分组”中。
- 分组筛选可与昵称、简介或 UID 搜索同时使用。可以勾选单个账号，或一键选中当前筛选结果；已经勾选的账号切换筛选后仍保持选中。
- 在底部选择操作：**加入分组**（保留原分组）、**移至分组**（替换原分组）、**设为／取消特别关注**、**取消关注**或**加入黑名单**。
- 选择分组操作时，还需选择目标分组。点击执行按钮后，先检查确认框中的账号名单和操作，再确认执行。
- 请求逐个发送，间隔 3 秒。点击“停止”会在当前请求结束后停止；已成功的操作不会自动撤销。
- 遇到登录、接口或网络错误会停止。尚未处理的账号仍保持选中，可以检查后继续。
- “重新加载”会重新读取列表，并清空当前选择与分组筛选。

## `-352` 请求被拦截

`-352` 表示 Bilibili 拒绝了该次请求。若先成功处理一批账号、随后返回 `-352`，而重试又在第一人失败，更符合操作频率或累计次数触发拦截且限制尚未解除。脚本保留此前已能成功执行的请求方式，操作间隔为 3 秒；0.3.3 版取消了每批 20 人的上限。3 秒间隔不保证避开平台限制。遇到 `-352` 时脚本立即停止，不会自动重试。请暂停操作，待限制解除后再少量验证，不要反复快速重试。

## 范围与限制

脚本只在网址形如 `https://space.bilibili.com/你的UID/relation/follow` 且登录 UID 与页面 UID 相同时显示。它使用 Bilibili 的关注列表、分组和关系操作接口，脚本不会把账号列表或登录校验信息发送到其他站点。接口发生变化、访问受限或网站限流时，面板会显示错误；列表未读完时只允许操作已读取的账号。分组读取失败时，分组操作不可用，其他操作仍可使用。

取消关注可能影响特别关注、互相关注等关系；加入黑名单也可能解除关注。执行前请仔细核对确认框。脚本不提供自动撤销功能。
