# BiliFollow

[English](./README.md)

**更轻松地整理你的 B 站关注列表。**

关注的人越来越多，不想再逐个打开主页处理？BiliFollow 会在**你自己的关注页**添加一个管理面板，帮你找到目标、勾选账号，然后一起操作。

## 它能帮你做什么？

- **更快找到想找的人。**按昵称、简介或 UID 搜索；只看未分组、特别关注，或一个、多个分组里的账号。
- **整理关注分组。**把账号加入新分组并保留原分组，或者移到新分组并替换原分组。
- **一次处理多个账号。**批量设为或取消特别关注、取消关注、加入黑名单。
- **操作前先核对。**逐个勾选账号，或选中当前筛选结果；执行前可以再次查看名单。

## 开始使用

1. 在浏览器中安装并启用 [Tampermonkey](https://www.tampermonkey.net/)。
2. 在 GitHub 打开 [BiliFollow 脚本](./bili-follow-manager.user.js)，点击 **Raw**，复制显示的全部内容。
3. 在 Tampermonkey 中选择「新建脚本」，用复制的内容替换编辑器里的原有文字，然后保存。
4. 登录 Bilibili，打开**你自己的关注页**并刷新，点击右下角的「管理关注」。

## 怎么操作？

1. 搜索账号，或选择想查看的分组。
2. 逐个勾选，或点击「选中筛选结果」。切换搜索或分组后，之前勾选的账号仍会保留；继续前请留意已选人数。
3. 在面板底部选择操作。整理分组时，还要选择目标分组。
4. 在确认窗口核对操作和账号名单，再点击确认。

执行过程中可以点击「停止」。已经完成的操作会保留，脚本无法自动撤销。取消关注可能影响特别关注或互相关注；加入黑名单也可能同时取消关注。

## 遇到问题？

- **没有看到「管理关注」？**确认 Tampermonkey 已启用、你已登录，并且打开的是**自己的**关注页，然后刷新页面。
- **操作因 `-352` 停止？**这是 Bilibili 拒绝了请求，请暂停一段时间再尝试。已完成的操作不会恢复，未处理的账号仍保持选中。
- **想重新开始？**点击「重新加载」刷新列表；已选账号和分组筛选也会被清空。
